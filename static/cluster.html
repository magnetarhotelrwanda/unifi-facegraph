Cluster Unknowns (local model)

Face Recognition ← Back to main

Compares every current unknown detection against every other unknown detection (not against known people) and groups the ones that look like the same face together — useful for spotting a recurring unidentified face (e.g. "the postman") so you can name or assign a whole batch at once, without needing to already have them assigned to someone.

Lower this if the same person is being split into too many small groups. Raise it if different people are getting merged into one group. Re-groups instantly — no need to recompute embeddings.
